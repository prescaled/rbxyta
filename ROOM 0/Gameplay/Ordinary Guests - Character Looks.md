# Ordinary Guests - Character Looks

**Requested by the user on 2026-10-26:** describe how the guests look so Codex (R+X) can build the characters, and make them **all different from each other**. This sheet covers the 13 first-build guests from [[Ordinary Guests - Index]] and the 9 people in the new [[Ordinary Guests - Family Bookings]], children included. Each look **expands the written one-line look** in the booking notes; it never contradicts it. Ages are from the notes where given, otherwise proposed.

## How to build them (for R+X)

- **Rig:** R15, built from a `HumanoidDescription`, so every guest is the same rig type and shares animations. Apply skin colour per body part, the scales below, and a few free catalog accessories (hair, glasses, hats, bags). No logos, brands or recognisable characters on clothes.
- **Scales:** height, width and head scale are given per person (Roblox defaults are 1.0). Keep `BodyTypeScale` and `ProportionScale` at 0 for everyone. Children use the child scales given and must still read clearly as children: shorter, slightly larger head.
- **Colours:** a person's **main colour** is the first thing you see. No two people in the same booking share a main colour, and no two of the 13 first-build guests share both main colour and silhouette.
- **Signature prop:** carried in a hand or on the body (welded, non-colliding). This is how players recognise someone from across the lobby. It also helps the check-in photo comparison.
- **Walk and idle:** one small difference each (speed, posture or idle gesture). These are tweaks to the shared animations, not new systems.
- **The file photo:** each guest's check-in photo is rendered from this same look, so an ordinary guest always matches it. Anomaly arrivals are built separately; never reuse an ordinary guest's exact look for an anomaly.

Colours are RGB.
