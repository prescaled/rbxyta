# Shift Tasks

The ordinary work of a shift. It gives players a reason to move around the [[Ashbourne Hotel]] and puts them where [[Incidents]] can happen.

| Task | What the player does | Where it can turn strange |
|---|---|---|
| Check guests in | Front-desk computer, keys, guest records | Guest list shows names that should not be there (like [[Daniel Mercer]]) |
| Deliver requested items | Carry items to rooms | Delivery to a room that does not exist on the floor plan |
| Investigate maintenance problems | Fix lights, doors, plumbing | A corridor is different from last shift |
| Monitor security cameras | Watch feeds in the security room | Someone stands behind a player in an empty corridor |
| Respond to calls from rooms | Answer the front-desk phone | A guest calls from a room that is supposed to be empty |

All five come from the [[Vision]]. They form the [[Roadmap#Phase 2 — Build the first shift|Phase 2]] task list.
