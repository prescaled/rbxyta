# ROOM 0 - Home

> Every room has a number.
> Every guest has a record.
> Every disappearance has an explanation.
> **Except Room 0.**

ROOM 0 is a multiplayer psychological mystery game on Roblox, set inside the fictional [[Ashbourne Hotel]], and told across TikTok, YouTube and Roblox. Watching the story makes you want to play, and playing makes you want to discover more of the story.

This is the **chosen direction** for the project. It replaces the earlier game concepts.

Visual version: [Miro board "ROOM 0 — Ashbourne Hotel"](https://miro.com/app/board/uXjVEVisZSo=/) (mind map and detailed notes).
