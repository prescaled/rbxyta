# Blender Model List

Every model needed for the [[Ashbourne Hotel]], grouped by task and area. **The goal is a very detailed hotel with a lot of different models, so there is always something to do.**

Priority: **P1** = first playable floor ([[Roadmap#Phase 2 — Build the first shift|Phase 2]]), **P2** = public launch ([[Roadmap#Phase 4 — Open the hotel|Phase 4]]), **P3** = later expansion. Build P1 first so the prototype is not blocked on art.

## Tips for building them
- Build **modular**: wall, floor, ceiling, door frame and corridor pieces on a fixed grid (for example 4 studs), so corridors can "change" by swapping pieces ([[Strange Events]]).
- Make **variants** of the same base (3 bed styles, 4 lamp styles) for detail without much extra work.
- Keep a **low-poly version** for Roblox mesh limits, and use textures for detail.
- One shared **colour and material palette** for the 1990s hotel look.
- Every interactive model needs a clear **interaction point** (handle, button, screen).
