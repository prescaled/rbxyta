# Roadmap

Five phases from the [[Vision]].

## Phase 1 — Establish the mystery
- Write the [[Ashbourne Hotel]]'s history ([[Timeline]]).
- Define the main characters ([[Daniel Mercer]], [[Hotel Management]], [[Missing Guests]]).
- **Decide the central secret** ([[Room 0#The secret]]).
- Create the visual identity of ROOM 0.
- Produce the first pilot videos ([[Pilot - Daniel Mercer]]) and test if people care about the mystery.

## Phase 2 — Build the first shift
- One detailed hotel floor.
- A reception area.
- Basic employee tasks ([[Shift Tasks]]).
- Several mysterious events ([[Incidents]], [[Strange Events]]).
- Random guest arrivals with multi-night stays and groups ([[Guests]]).
- End-of-shift inspection with coins, a basic [[Hotel Shop]] and [[Variable Rewards]].
- The P1 models from the [[Blender Model List]].
- A first version of the [[Spawn Island]] with working [[Lobbies]], 2 to 3 [[Classes]], and [[Health]].
- Result: the first playable prototype.

## Phase 3 — Connect the stories
- Release more Shorts while adding discoveries to the game.
- Viewers start recognising details shared between the videos and the hotel ([[Player Experience#The video-to-game bridge]]).

## Phase 4 — Open the hotel
- Launch a public version once it is stable and genuinely enjoyable.
- Videos start directing viewers to investigate the hotel themselves ([[The Discoveries]]).

## Phase 5 — Expand the universe
- New hotel areas, guest histories, mysteries and story chapters.
- The world grows through both gameplay and short-form storytelling.
